### Группировка категориальных данных

NumPy не предоставляет прямого аналога всех возможностей группировки Pandas, но некоторые задачи можно решать с помощью `np.unique()` и `np.bincount()`.
unique_regions, region_idx = np.unique(
    region,
    return_inverse=True
)

revenue_by_region = np.bincount(
    region_idx,
    weights=revenue
)
Массив `region_idx` содержит числовой индекс региона для каждой записи. `np.bincount()` суммирует значения по этим индексам.

Для расчёта среднего по группам можно разделить сумму на количество наблюдений, предварительно проверив отсутствие групп с нулевым количеством наблюдений.
